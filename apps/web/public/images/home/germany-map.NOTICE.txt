Source data
  - Country outlines: Natural Earth 1:10m Cultural Vectors, Admin 0 – Countries,
    via the world-atlas npm package v2.0.2 (countries-10m.json, TopoJSON)
    https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-10m.json
  - Bundesländer (state) borders: Natural Earth 1:10m Admin 1 – States, Provinces
    (boundary lines), natural-earth-vector v5.1.2
    https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_10m_admin_1_states_provinces_lines.geojson

How it is made
  Generated, not drawn: apps/web/scripts/build-germany-map.mjs downloads the
  data, projects it (equirectangular, x scaled by cos of Germany's mid
  latitude), clips the neighbours to the view, simplifies, and writes this SVG
  plus apps/web/app/components/home/germany-map.ts (the pin positions, projected
  with the same constants). Rerun the script instead of editing either output.
